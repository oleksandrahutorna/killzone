# KILLZONE

KILLZONE — промосайт і Windows-збірка динамічного 2D survival-шутера. У грі потрібно досліджувати зони, відбивати хвилі ворогів, збирати монети та готуватися до бою з босом.

## Склад проєкту

```text
killzone/
├── index.html           # сторінка сайту
├── style.css            # оформлення й адаптивна верстка
├── script.js            # інтерактивність сторінки
├── Killzone.exe         # копія виконуваного файла гри
├── downloads/
│   └── Killzone.exe     # файл гри, на який ведуть посилання сайту
└── README.md
```

Файл у `downloads/` призначений для завантаження із сайту. Обидві копії `Killzone.exe` у репозиторії мають збігатися, якщо оновлюється версія гри.

## Перегляд сайту

Сайт не потребує збирання або встановлення залежностей. Щоб переглянути його, відкрийте `index.html` у сучасному браузері.

За потреби сайт можна запустити через локальний HTTP-сервер. Наприклад, якщо у вас встановлений Python:

```powershell
py -m http.server 8000
```

Потім відкрийте <http://localhost:8000>. Щоб зупинити сервер, натисніть `Ctrl+C` у вікні термінала.

## Завантаження та запуск гри

Гра призначена для комп’ютерів із Windows; версії для телефона сайт не надає.

1. На сайті натисніть **«Завантажити гру»** або відкрийте файл [`downloads/Killzone.exe`](downloads/Killzone.exe).
2. Збережіть файл на комп’ютері.
3. Відкрийте `Killzone.exe` у Windows.
4. Якщо Windows показує попередження безпеки, запускайте файл лише якщо довіряєте джерелу, з якого його отримали.

Для запуску гри окремо встановлювати Python не потрібно. Окремі вимоги до апаратного забезпечення в проєкті не вказані.

| Боєць | Роль | Здоров’я | Швидкість | Стрибок | Стартова зброя |
| --- | --- | ---: | ---: | ---: | --- |
| Vanguard | Захисник | 120 | +0 | +0 | Glock |
| Blaze | Бігун | 90 | +22 | +18 | UMP |

На сайті Vanguard позначений як безкоштовний і вже відкритий. Вартість Blaze — 50 монет, Ghost — 80, Sentinel — 100. Покупки здійснюються у внутрішньоігровому магазині за монети.

Наведені нижче ціни та показники шкоди взято з каталогу на сайті. Купувати спорядження можна за внутрішньоігрові монети.

| AKM | Штурмова зброя | 30 | 46 монет |

## Промокоди

Промокоди відкривають доступ до додаткових мап. Натисніть **«Отримати промокод»** у відповідній картці на сайті, скопіюйте код, а потім у головному меню гри натисніть `P`, введіть його та натисніть `Enter`.


Сайт також має кнопку копіювання коду. Якщо браузер не дозволяє копіювати в буфер обміну, код можна виділити й скопіювати вручну.

## Можливості сайту

- адаптивна навігація з меню для вузьких екранів;
- галерея знімків із кнопками перемикання та підтримкою гортання на сенсорних екранах;
- вкладки каталогу бійців і зброї;
- картки промокодів із розкриттям і копіюванням коду;
- розділи про бійців, спорядження, ігровий світ і відповіді на поширені запитання.

Сайт можна переглядати на телефоні чи планшеті, але сама гра запускається у Windows.

## Оновлення та публікація сайту

1. Змініть вміст `index.html`, `style.css` або `script.js` відповідно до задачі.
2. Перевірте сторінку у браузері, зокрема вузький і широкий розміри вікна, навігацію, галерею, вкладки магазину та промокоди.
3. Для публікації розмістіть `index.html`, `style.css`, `script.js` і каталог `downloads/` разом на статичному вебхостингу. Збережіть відносний шлях `downloads/Killzone.exe`, інакше посилання на завантаження перестануть працювати.
4. Після заміни збірки гри оновіть файл у `downloads/`; якщо коренева копія `Killzone.exe` теж використовується, замініть і її.

У репозиторії немає автоматизованих команд збирання чи тестування сайту.
